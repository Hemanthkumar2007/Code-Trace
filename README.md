# CodeTrace Final Hackathon — npm Version

## Run on Windows

Open PowerShell in this folder:

```powershell
npm install
npm run dev
```

Vite will print a local URL, normally:

`http://localhost:5173/`

Keep PowerShell open while running the app.

## Demo accounts
- Student: student@codetrace.local / student123

## Included
- npm/Vite project
- Student/teacher/admin roles
- Assignments and problem library
- Coding editor
- Keyboard insert/delete tracking
- Paste/copy/cut/undo/redo telemetry
- Pause detection
- Large insertion detection
- Snapshots and replay
- JavaScript test execution for built-in problems
- Feature extraction
- Explainable rule-based risk score
- Historical baseline deviation
- Teacher investigation dashboard
- AI disclosure
- Reports and JSON export
- Audit log
- Fairness guardrail

## Important
This is a hackathon-ready prototype, not a production LMS. It does not claim a trained real-world ML model, production authentication, or a secure arbitrary-code execution sandbox. Those require representative labeled data and isolated backend infrastructure.
